# MindSpace

A student well-being web app for self-reflection and learning. Educational only, not a diagnostic or medical tool.

## Files
- `index.html` – page structure (Home, Track, Learn, Breathe, Habits)
- `style.css` – all styling (colours are at the top, in `:root`)
- `script.js` – app logic; data is saved in the browser (localStorage) only

## Run locally
Open `index.html` in a browser. Keep all three files in the same folder.

## Deploy (Vercel)
1. Upload the files to the root of a GitHub repo.
2. Import the repo on vercel.com, leave all settings as they are, click Deploy.
